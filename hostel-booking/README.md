# Хостел · бронирование коек

Одностраничное приложение для учёта койко-мест в хостеле.

## Возможности

- **Вход / регистрация**
  - Вход по email и паролю (Supabase Auth).
  - Регистрация только по приглашению от владельца.
  - Восстановление пароля по email.
- **Карта мест**
  - Квартиры → комнаты (A/B/C/E) с кроватями.
  - Капсульные боксы («белое дерево»).
  - В каждой квартире отмечены туалет, кухня и общая зона.
- **Брони**
  - Таблица всех броней с поиском, фильтрами, статусами (живёт / заезд позже / выехал).
  - Оплата и сумма (ночей × цена).
  - Двойное бронирование одной койки на пересекающиеся даты блокируется.
- **Календарь (шахматка)**
  - Просмотр броней по дням и койкам.
  - Быстрое создание брони по клику на свободный день.
- **Бухгалтерия**
  - Учёт расходов и дополнительных доходов по статьям.
  - Повтор расходов прошлого месяца.
  - Прибыль, маржа, долги гостей.
- **Аналитика**
  - Заполняемость, ADR, средняя длительность проживания.
  - Новые/вернувшиеся/выехавшие гости.
  - Графики по дням, месяцам, топ квартир, должники.
- **Структура**
  - Редактор зданий, квартир, комнат, коек.
  - Добавление, удаление, изменение количества мест.
- **Команда**
  - Владелец может приглашать менеджеров.
  - Настройка приватности телефонов (виден только автору брони или всей команде).
- **Данные**
  - Все данные хранятся в облаке (Supabase) и синхронизируются между устройствами.
  - Кнопки Экспорт/Импорт (JSON-резервная копия).
- **Локализация**
  - Русский, английский, арабский (RTL).

## Технологии

- **Frontend**: чистый HTML/CSS/JavaScript (без фреймворков).
- **Backend**: Supabase (PostgreSQL + Auth + REST API).
- **Деплой**: Vercel.

## Роли и права

- **Владелец**
  - Полный доступ ко всем данным хостела.
  - Управление структурой, бронью, финансами.
  - Приглашение и удаление менеджеров.
  - Изменение настроек приватности телефонов.
- **Менеджер**
  - Видит структуру, брони, календарь, финансы, аналитику.
  - Может создавать/изменять брони и финансовые операции.
  - Не имеет доступ к вкладке «Команда» и настройкам.
  - Телефоны чужих броней видны только если приватность выключена.

## Регистрация и создание владельца

- Новый пользователь может зарегистрироваться **только при наличии приглашения**.
- Владелец хостела создаётся **вручную через Supabase**.
- Инструкция: см. `database/SETUP-SUPABASE.md`.

## Настройка и запуск

### Подключение Supabase

1. Создайте проект в Supabase.
2. Выполните SQL-миграции из папки `database/` по порядку (см. `database/SETUP-SUPABASE.md`).
3. Вставьте `SUPABASE_URL` и `SUPABASE_KEY` в `app/01-constants.js`.
4. Создайте владельца хостела (см. `database/SETUP-SUPABASE.md`).

### Локальный запуск

- Через VS Code Live Server: открыть `index.html` правой кнопкой → **Open with Live Server**.
- Или через Python:
  ```bash
  python -m http.server 5501
  ```
  Откройте `http://localhost:5501`.

### Деплой на Vercel

```bash
npm i -g vercel
vercel --cwd . --prod --yes
```

## Структура проекта

- `app/` — логические модули приложения (от констант до инициализации).
- `i18n/` — словари локализации и движок.
- `assets/` — иконки, логотипы, Supabase SDK.
- `database/` — SQL-миграции и инструкция по настройке Supabase.
- `styles.css` — все стили.
- `index.html` — разметка и подключение скриптов.

## Примечания

- Публичный ключ Supabase безопасен при включённом RLS.
- Секретные ключи не должны попадать в браузер.
- Данные разных хостелов изолированы RLS.
