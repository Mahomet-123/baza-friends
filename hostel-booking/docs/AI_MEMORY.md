# AI_MEMORY — Памятка для ИИ

## Суть
SPA для управления койко-местами в хостеле. Чистый JS + Supabase. RU/EN/AR.

## Ключевые файлы
- `index.html` — разметка.
- `app/` — 19 модулей (инициализация, данные, UI).
- `i18n/` — три словаря + движок.
- `database/` — SQL-миграции и инструкции.
- `tests/` — модульные и интеграционные тесты.

## Бизнес-логика
- Владелец создаётся вручную, менеджеры по приглашению.
- Бронирование с проверкой пересечений, оплата, статусы.
- Финансы, аналитика, календарь, команда.
- Оптимистичная блокировка (`updated_at`).
- Кастомные модалки и тосты.

## Важные нюансы
- Регистрация только по приглашению (`has_invite`).
- Supabase Auth + RLS.
- Валюта — ₽.
- Автообновление каждые 30 сек.
- Тесты: 17 чистых функций + 22 интеграционных.
