# STEP_BY_STEP_REBUILD — Как воссоздать проект с нуля

1. Создать Supabase проект.
2. Выполнить SQL-миграции по порядку из `database/`.
3. Создать функцию `has_invite`.
4. Настроить SMTP (опционально).
5. Получить ключи и вставить в `app/01-constants.js`.
6. Создать владельца через `supabase-insert-owner.sql`.
7. Развернуть файлы проекта (структура как в `PROJECT_MAP`).
8. Запустить локально или на Vercel.
9. Проверить вход, бронирование, команду.
10. Запустить тесты (`tests/tests.html` и `tests/integration.html`).
