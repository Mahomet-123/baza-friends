# Дерево проекта baza-friends

Монорепо: **публичный сайт** (статический SPA, пространство имён `BF`) + **CRM-админка** (`hostel-booking/`, реальный Supabase). Термин юнита в CRM — **«апартамент»**, на публичном сайте — **«объект»**.

## Правила, принятые в проекте
- **Язык общения и кода (кроме идентификаторов):** русский.
- **Git:** коммит всегда в **новую ветку** → merge в `main` → push. Прямой коммит в `main` запрещён.
- **Структура файлов:** ≤200–250 строк/файл, 1 файл = 1 ответственность, именование по БЭМ, переиспользуемое выносить сразу.
- **No-bundler SPA:** общий namespace `window.BF` (сайт) / модули CRM грузятся по порядку в `index.html`.
- **Дерево проекта** строится и поддерживается при каждой задаче (см. этот файл).
